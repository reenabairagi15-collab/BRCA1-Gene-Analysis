# BRCA1 Gene Analysis - Breast Cancer Mutation Study

## Overview
Analyzed Human BRCA1 gene (1863 aa) which is responsible for DNA repair and associated with Hereditary Breast and Ovarian Cancer. This project focuses on understanding mutations that increase cancer risk.

## Objectives
- To retrieve BRCA1 gene sequence from NCBI
- To analyze protein length and function
- To study pathogenic mutations

## Tools & Technologies
- Python & Biopython
- NCBI Gene & PubMed Database
- FASTA Format
- GitHub for Version Control

## Key Results
- **Gene Location:** Chromosome 17q21.31
- **Protein Length:** 1863 amino acids
- **Molecular Function:** Tumor Suppressor, DNA Repair, Homologous Recombination
- **Clinical Significance:** Mutation increases Breast Cancer risk by 55-72% and Ovarian Cancer risk by 39-58%

## Conclusion
BRCA1 is a critical tumor suppressor gene. Early mutation analysis can help in early diagnosis and preventive healthcare.
